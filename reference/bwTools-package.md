# bwTools: Native R tools for genomic signal tracks

Native R tools for reading, writing, retrieving, merging, summarizing,
and benchmarking BigWig, WIG, and bedGraph signal tracks. Public
analysis functions operate on the standardized BwgTrack schema v2 and
use 1-based closed coordinates.
